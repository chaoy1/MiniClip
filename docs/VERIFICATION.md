# 验证说明

MiniClip 提供 Windows 桌面自检，用于检查剪贴板、快捷键、窗口样式、历史存储及界面渲染。自检结果反映运行它的机器和构建版本；发布前仍须完成真实桌面操作与安装验证。

## 运行自检

先按 [构建说明](BUILD.md) 生成 Release 版本，再执行：

```powershell
.\src\MiniClip\bin\Release\net10.0-windows\MiniClip.exe `
  --selftest .\artifacts\selftest
```

每项检查输出 `[PASS]` 或 `[FAIL]`；全部通过时最后输出 `ALL CHECKS PASSED`，进程退出码为 `0`。自检会向指定目录写入 `selftest.log` 和 WPF 界面截图。检查项会随实现变化，因此不应以固定数量判断是否通过。

自检会临时注册快捷键、创建托盘图标，并读写系统剪贴板。运行前请先使用或保存当前剪贴板内容，避免与其他剪贴板自动化同时执行。自检结束后临时托盘图标会注销。

## 覆盖范围

当前自检代码位于 [`SelfTest.cs`](../src/MiniClip/Diagnostics/SelfTest.cs)，主要覆盖：

| 范围 | 检查内容 |
| --- | --- |
| Windows 集成 | 消息窗口、全局快捷键、键盘钩子、剪贴板文本往返、托盘图标和候选窗口的无激活样式。 |
| 历史与数据 | 去重与容量限制、存储读写、数据目录回退、历史文件读取失败后的保护、清空过程中的并发事件。 |
| 粘贴安全 | 目标窗口变化、粘贴期间的新复制、过期剪贴板通知和粘贴顺序。 |
| 界面 | 主题、设置、菜单、确认窗口、文字光标定位回退、列表滚动及截图输出。 |
| 诊断 | 日志保留规则、性能样本及内存读数。性能与内存项仅提供当前环境的数据，不代表所有机器。 |

## 发布前人工检查

在目标 Windows 版本和实际输入应用中完成以下操作，并记录构建版本、系统版本、显示缩放与结果：

1. 安装包：首次安装、自定义安装路径、可选开机启动、升级以及卸载。卸载前备份需要保留的历史。
2. 免安装包：在具备 .NET 10 Desktop Runtime 的机器上解压并启动，确认压缩包中全部文件齐全。
3. 输入场景：不同窗口和显示缩放下打开候选框，用真实键盘选择与粘贴；确认原输入框保持焦点。
4. 异常场景：快捷键被占用、目标窗口在选择期间变化、管理员权限窗口、未提供光标坐标的应用。
5. 数据场景：确认历史文件位置、明文提示、清空历史和卸载删除范围。

自检不能替代真实鼠标操作、跨应用可访问性行为或干净机器上的安装验证。代码签名和 SmartScreen 提示也需要在实际分发环境检查。
