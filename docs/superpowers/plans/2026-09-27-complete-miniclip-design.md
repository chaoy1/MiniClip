# MiniClip 剩余设计与清理任务实施计划

**目标：** 将已展示的 252 DIP 紧凑弹窗、文字光标定位、黑白设置窗和自定义托盘菜单落实到 Windows 程序，并清理 7 天前的诊断日志。

**已有实现：** 弹窗浅色/深色主题、底栏移除、历史最多 100 条及磁盘同步已经完成；本计划保留这些行为。

## 1. 紧凑弹窗与顺序

- [x] 修改 `PopupWindow.xaml` 和 `PopupWindow.xaml.cs`：宽 252 DIP、26 DIP 单行、最多 5 行、8 DIP 圆角；历史按旧到新显示，最新默认选中最下方。
- [x] 更新导航与长列表自检：向上访问旧记录，向下回到新记录，选中项始终可见。
- [x] 检查浅色/深色 PNG 截图与 100 条滚动截图。

## 2. 文字光标定位

- [x] 在 `Win32Focus` 中从前台线程的 `GetGUIThreadInfo.rcCaret` 取得屏幕坐标；不可用时使用当前焦点控件的位置，最后才使用前台窗口的位置。
- [x] 控制器打开弹窗时传入定位点；列表刷新沿用同一个锚点，不再查询鼠标。
- [x] 检查工作区边缘钳制与不抢焦点行为；多屏混合 DPI 的真实桌面效果列入当前验收记录待人工确认。

## 3. 诊断日志

- [x] `DiagnosticsLog.Start` 在默认日志目录启动时做一次清理：保留最近 7 天；限制单文件 1 MB、目录合计 10 MB；只处理 MiniClip 诊断日志，不触碰历史和设置。
- [x] 用临时目录验证旧文件删除、体积限额、当前文件保留；文件访问失败时跳过，不影响主程序。

## 4. 其余视觉界面
